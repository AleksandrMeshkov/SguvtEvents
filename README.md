# СГУВТ Events - Портативный бандл

## Описание

Портативное веб-приложение для управления мероприятиями СГУВТ. Работает на любой Windows-машине без установки дополнительного программного обеспечения.

## Использование

### Запуск приложения

1. Запустите файл `start_server.bat`
2. Дождитесь сообщения "Сервер запущен!"
3. Откройте браузер: **http://localhost:8080**
4. Для остановки закройте окно командной строки

### Первый запуск

При первом запуске автоматически:
- Инициализируется база данных
- Создаются таблицы
- Заполняются тестовые данные (70+ мероприятий)

### Сброс базы данных

1. Запустите файл `reset.bat`
2. Подтвердите действие вводом "да"
3. База данных, логи и кэш будут удалены
4. При следующем запуске `start_server.bat` база будет инициализирована заново

**Важно:** Скрипт автоматически остановит запущенные серверы перед сбросом.

## Функциональность

### Основные возможности

- **Реестр мероприятий** - просмотр, фильтрация по дате, институту, факультету
- **Добавление/редактирование** - создание и изменение мероприятий
- **Справочники** - управление институтами, факультетами, категориями
- **Отчёты** - аналитика по мероприятиям с метриками
- **Экспорт** - выгрузка данных в PDF и Word форматы

### Фильтрация данных

- По периоду (с даты по дату)
- По институту
- По факультету

### Экспорт данных

- **PDF** - экспорт реестра мероприятий и отчётов
- **Word** - экспорт в формате DOCX
- **Печать** - прямая печать из браузера

## Разработка

### Публикация через GitHub

GitHub хранит исходный код проекта, но GitHub Pages не запускает PHP и MariaDB. Для рабочего сайта нужен хостинг с PHP 8.3 и MySQL/MariaDB либо VPS. Репозиторий можно подключить к хостингу через Git или GitHub Actions.

Перед публикацией:

1. Создайте репозиторий на GitHub и загрузите содержимое проекта.
2. Не загружайте папки `server/`, `logs/` и файл `.env` — они исключены в `.gitignore`.
3. На хостинге создайте базу данных и импортируйте `sql/create_db.sql`, затем при необходимости `sql/fill_db.sql`.
4. Используйте `.env.example` как шаблон и задайте эти переменные в настройках окружения хостинга; файл `.env` на сервер загружать не нужно.
5. Настройте корневой каталог сайта на папку `src/`.

Для локального запуска с портативным комплектом используйте `start_server.bat`. Он требует папку `server/`, которая намеренно не входит в GitHub-репозиторий.

### Запуск через Docker на Ubuntu

На Ubuntu используйте Docker Compose, а не `start_server.bat`:

```bash
git clone https://github.com/AleksandrMeshkov/SguvtEvents.git sguvt-events
cd sguvt-events
cp .env.example .env
nano .env
docker compose up -d --build
```

В `.env` замените `DB_PASS` и `DB_ROOT_PASS` на сложные пароли. После запуска приложение доступно на порту `APP_PORT` (по умолчанию `8080`):

```text
http://IP_СЕРВЕРА:8080
```

База данных автоматически создаётся при первом запуске контейнера. Данные MariaDB хранятся в Docker volume `db_data`. Для работы экспорта PDF/Word скопируйте `server/libs/libs.phar` в одноимённый каталог на сервере: папка `server/` исключена из GitHub.

```bash
docker compose logs -f app
docker compose down
```

Не используйте `docker compose down -v`, если нужно сохранить базу данных.

### Структура исходного кода

- `src/includes/config.php` - Конфигурация БД и константы
- `src/includes/autoload.php` - Автозагрузчик классов (поддерживает PHAR и исходники)
- `src/includes/functions.php` - Вспомогательные функции
- `src/includes/ExportHelper.php` - Класс для экспорта в PDF/Word
- `src/models/` - Модели данных (Event, Institute, Faculty, Category, Participant)

### Режим разработки

Для разработки без сборки PHAR:
1. Удалите `server/libs/libs.phar`
2. Создайте папку `src/lib/` и поместите туда исходники библиотек:
   - `tcpdf/` - библиотека TCPDF
   - `phpword/` - библиотека PHPWord
   - `laminas-escaper/` - библиотека Laminas Escaper
   - `phpoffice/math/` - библиотека PhpOffice Math
3. Автозагрузчик автоматически переключится на режим разработки

### Требования для разработки

- **PHP 8.3** (для локальной разработки)
- **MariaDB 10.11** (для локальной разработки)
- **Composer** (для установки зависимостей в режиме разработки)

## Технические детали

### Архитектура

- **Frontend**: HTML5, CSS3, JavaScript (vanilla)
- **Backend**: PHP 8.3 (встроенный сервер)
- **База данных**: MariaDB 10.11
- **Библиотеки**: TCPDF (PDF), PHPWord (DOCX)

### Безопасность

- MariaDB слушает только на 127.0.0.1
- PHP не раскрывает версию (`expose_php = Off`)
- Все процессы запускаются в фоне
- Используется PDO с prepared statements
- Валидация и санитизация входных данных

### Производительность

- InnoDB buffer pool: 128M
- Максимум подключений: 100
- Лимит памяти PHP: 256M
- Максимальное время выполнения: 60 сек

### Портативность

- Все пути используют абсолютные пути от расположения скрипта
- Конфигурационные файлы переопределяют пути через аргументы командной строки
- Не требует установки дополнительного программного обеспечения
- Работает на любой Windows машине (Windows 7/8/10/11)

## Системные требования

## Устранение неполадок

### Порт 3306 уже занят
```
ОШИБКА: Порт 3306 уже занят! Возможно, уже запущен другой MySQL сервер.
```
**Решение:** Остановите другой MySQL сервер или измените порт в `server/mysql/my.ini`.

### Порт 8080 уже занят
```
ОШИБКА: Порт 8080 уже занят!
```
**Решение:** Остановите приложение, использующее порт 8080, или измените порт в `start_server.bat`.

### MariaDB не запустился
```
ОШИБКА: MariaDB не запустился.
```
**Решение:** Проверьте логи в папке `logs/mysql_error.log`. Попробуйте запустить `reset.bat` для сброса базы данных.

### Ошибка подключения к БД
```
Ошибка подключения к БД. Сервер временно недоступен.
```
**Решение:** Убедитесь, что `start_server.bat` запущен. Проверьте логи в папке `logs/`.
